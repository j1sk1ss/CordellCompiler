CordellCompiler

A tiny page served by cpllib/http. It verifies that a CPL program can start a localhost server and return HTML from a file.

Compiler

CordellCompiler lowers CPL source through intermediate representations into assembly and a native binary. This example is a regular CPL program without an external web framework.

Library

cpllib provides thin C/POSIX declarations and compact containers. The new http_server registers route handlers, accepts a TCP connection, and writes an HTTP response.
